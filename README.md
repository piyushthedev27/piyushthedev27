> Three real products. Deployed. Working. Used.

<br/>

**`№ 01`** &nbsp; **[FlexiStudy — AI Learning Platform](https://flexi-study.vercel.app/)**

```
Flutter · Firebase · Groq API · GetX · Android + iOS
```

An adaptive learning app that doesn't just explain concepts — it rewrites them in the style that works for *you*. Visual learner? Step-by-step? Analogy-first? The AI figures it out. Built cross-platform from a single codebase with offline caching and Firebase auth.

**`№ 02`** &nbsp; **[IdeaZen — AI Project Idea Generator](https://ideazen.vercel.app/)**

```
React 18 · TypeScript · Groq / Llama 3.3 70B · Vercel Serverless
```
